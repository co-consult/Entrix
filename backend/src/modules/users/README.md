# Module Users - Entrix V3.0 
 
Module epure pour la gestion des utilisateurs et groupes. 
L'authentification est geree par le module Auth separe. 
 
## Fonctionnalites 
- Gestion utilisateurs (CRUD, profils, recherche) 
- Systeme de groupes avec permissions 
- Gestion utilisateurs anonymes 
- Onboarding intelligent 
- Conversion anonyme vers enregistre 
- Invitations et gestion membres 
 
## Modules lies 
- **Module Auth** : Authentification JWT, login/logout 
- **Module Permissions** : RBAC systeme, roles 
- **Module Admin** : Audit, monitoring securite
